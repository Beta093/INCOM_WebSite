# Public joining form preview

`/join/` is a public UI prototype, separate from the existing-member portal at `/members/`.

- Three steps: basic information, interests, review; native validation, edit/back navigation and a preview completion screen.
- No real applications are accepted. No network submission, analytics, browser storage or draft persistence. Input is reset after the preview finishes; users are instructed to use fictional information.
- Recruitment dates, fees and selection procedures are deliberately unspecified pending organizer confirmation. No invented official requirements or acceptance promises.
- Before collecting real data: confirm eligibility and required fields; publish the actual data controller, purposes, collection fields, retention/deletion period and required/optional consent choices; connect a protected backend and staff-only review interface, validation, anti-abuse controls and receipts. Do not publish responses in repository files or expose them to all club members.
- Joining the club and signing into the Discord-role-based member portal are distinct workflows. No automatic Discord role assignment or admission is implemented here.
