# INCOM Website — Exhibition Draft

인하대학교 컴퓨터 연구분과 중앙동아리 INCOM의 홈페이지 리디자인 초안입니다.

기존 사이트의 소개, 역사, 활동, 성과, 연락처 콘텐츠를 유지하면서 오브젝트 기반의
디지털 전시 공간처럼 탐색할 수 있도록 시각 구조와 인터랙션을 새롭게 구성했습니다.

## 미리 보기

별도 설치 없이 `index.html`을 열거나 아래 명령으로 로컬 서버를 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 구성

- `index.html` — 전체 콘텐츠와 접근성 구조
- `styles.css` — 반응형 전시형 비주얼 시스템
- `script.js` — 스크롤 등장, 오브젝트 패럴랙스, 활동 전환, 모바일 메뉴
- `assets/` — 기존 INCOM 공개 사이트에서 보존한 로고와 활동 이미지

현재 버전은 디자인 방향을 검토하기 위한 첫 초안이며 정식 배포본이 아닙니다.
