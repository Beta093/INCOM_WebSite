# INCOM — A space for curious minds

인하대학교 컴퓨터 연구분과 중앙동아리 INCOM의 홈페이지 리디자인 초안입니다.

기존 사이트의 소개, 역사, 활동, 성과, 연락처 콘텐츠를 유지하면서 오브젝트 기반의
디지털 전시 공간처럼 탐색할 수 있도록 시각 구조와 인터랙션을 새롭게 구성했습니다.

## 미리 보기

별도 패키지 설치 없이 아래 명령으로 로컬 서버를 실행합니다.
3D ES 모듈을 사용하므로 파일을 직접 여는 대신 HTTP 서버로 접속해야 합니다.

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 열면 됩니다.

## 구성

- `index.html` — 전체 콘텐츠와 접근성 구조
- `gallery.css` — INCOM 블루·쿨그레이·실버 팔레트와 반응형 편집형 레이아웃
- `gallery.js` — 커튼 오프닝, 활동 기둥·사진 시차·명암 전환·로고 띠의 스크롤 연동, 모션 일시정지
- `origin-scene.js` — 회로도 기반 연혁, 활성 노드·작은 데이터 신호·절제한 시점 이동 (SVG)
- `scene.js` — 드래그 가능한 실제 WebGL 조형물과 절전 렌더링
- `assets/` — 기존 INCOM 공개 사이트에서 보존한 로고와 활동 이미지
- `assets/vendor/` — Three.js 0.180.0 고정 버전과 MIT 라이선스
- `assets/fonts/` — 눈누의 Paperlogy 웹폰트(400·500·600·700)와 SIL Open Font License. 이전 Pretendard는 보관만 하며 로드하지 않습니다.

## 디자인 방향

- 상단 내비게이션 없이 화면 전체로 시작하는 전시. 바로가기는 푸터에 배치합니다.
- 대표색은 파란색. 이 초안의 블루는 `#2457ed`이며 공식 색상 코드가 정해지면 교체할 수 있습니다.
- 짧은 블루 커튼 오프닝 → 크롬 매듭과 파란 구체 → 사진 중심 활동 아카이브.
- 한글·영문 타이포를 로컬 Paperlogy로 통일합니다. 제목과 본문의 굵기를 구분하고 폰트 폭에 맞춰 타이포 크기·행간을 조정했습니다.
- 별·스티커·장식용 세리프체를 제거하고, 로고·활동 사진·타이포를 중심으로 구성합니다.
- 첫 화면 CURIOUS BY NATURE의 대형 타이포·블루·금속성 조형물·작은 주석을 전체 스타일의 기준으로 유지합니다. 첫 화면 자체는 변경하지 않았습니다.
- 소개는 큰 원본 로고, 전시 캡션과 주석선, 검정·회색 타이포로 구성합니다. 로고 부유와 주석선 애니메이션을 겹칩니다.
- 활동은 왼쪽 파란 기둥 하나가 스크롤을 따라 내려가고, 오른쪽 사진·설명이 이어집니다. 배경은 흰색 → 검정 → 흰색으로 바뀌며, 간격을 소폭 늘려 읽는 호흡을 확보했습니다.
- 활동과 연혁 사이에는 원본 INCOM 로고와 워드마크가 스크롤에 따라 수평 이동하는 띠를 배치합니다.
- 연혁은 밝은 회로도 위의 세 노드가 순차적으로 강조됩니다. 과한 우주 연출 대신 약한 원근 이동과 작은 데이터 신호만 사용합니다. 추가 스크롤은 800px이며 버튼으로 시점을 바로 선택할 수 있습니다.
- 동작 줄이기 또는 모션 일시정지 시 활동은 밝은 배경, 연혁은 정적인 전체 목록으로 표시하고 로고 띠를 멈춥니다. 연혁 모듈 실패 시에도 내용을 읽을 수 있습니다.
- 성과는 수상 목록, 연락처는 블루 배경의 대형 한글 타이포로 구성합니다.
- 소개·역사·세부 활동·수상 내역·연락처를 보존합니다. 운영진은 기존 사이트로 연결합니다.
- 동작 줄이기 설정, 모션 일시정지, 화면 밖/백그라운드 렌더링 중지 지원.
- WebGL을 사용할 수 없어도 기존 오브젝트 이미지와 모든 본문이 표시됩니다.
