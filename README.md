# INCOM — A space for curious minds

인하대학교 컴퓨터 연구분과 중앙동아리 INCOM의 홈페이지 리디자인 초안입니다.

기존 사이트의 소개, 역사, 활동, 성과, 연락처 콘텐츠를 유지하면서 오브젝트 기반의
디지털 전시 공간처럼 탐색할 수 있도록 시각 구조와 인터랙션을 새롭게 구성했습니다.

## 미리 보기

별도 패키지 설치 없이 아래 명령으로 로컬 서버를 실행합니다.
3D ES 모듈을 사용하므로 파일을 직접 여는 대신 HTTP 서버로 접속해야 합니다.

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 열면 됩니다.

검증: `node tests/site-check.mjs`로 로컬 링크·이미지 경로·앵커와 운영진 11명의 누락/중복을 확인합니다. `node --check gallery.js`, `node --check pages.js`, `node --check origin-scene.js`로 구문을 검사합니다.

## 구성

- `index.html` — 전체 콘텐츠와 접근성 구조
- `gallery.css` — INCOM 블루·쿨그레이·실버 팔레트와 반응형 편집형 레이아웃
- `gallery.js` — 커튼 오프닝, 활동 기둥·사진 시차, 연혁에서 수상 항목까지 이어지는 선, 모션 일시정지
- `team/index.html` — 원본 데이터·공식 직책 캐릭터를 보존한 46기 운영진 페이지 (`/team/`)
- `pages.css`, `pages.js` — 운영진·404의 공통 디자인, 스크롤 등장과 모션 제어
- `404.html` — 메인으로 돌아가는 오류 페이지. 호스팅 환경에서 이 파일을 404 응답으로 지정해야 합니다. 기본 Python 서버에서는 `/404.html`로 직접 확인합니다.
- `origin-scene.js` — 스크롤로 그려지는 회로선, 도달한 노드의 등장, 스크롤 위치에 고정된 표시점 (SVG)
- `scene.js` — 드래그 가능한 실제 WebGL 조형물과 절전 렌더링
- `assets/` — 기존 INCOM 공개 사이트에서 보존한 로고와 활동 이미지
- `assets/vendor/` — Three.js 0.180.0 고정 버전과 MIT 라이선스
- `assets/fonts/` — 눈누의 Paperlogy 웹폰트(400·500·600·700)와 SIL Open Font License. 이전 Pretendard는 보관만 하며 로드하지 않습니다.

## 디자인 방향

- 상단 내비게이션 없이 화면 전체로 시작하는 전시. 바로가기는 푸터에 배치합니다.
- 대표색은 파란색. 이 초안의 블루는 `#2457ed`이며 공식 색상 코드가 정해지면 교체할 수 있습니다.
- 짧은 블루 커튼 오프닝 → 크롬 매듭과 파란 구체 → 사진 중심 활동 아카이브.
- 한글·영문 타이포를 로컬 Paperlogy로 통일합니다. 제목과 본문의 굵기를 구분하고 폰트 폭에 맞춰 타이포 크기·행간을 조정했습니다.
- 별·스티커·장식용 세리프체를 제거하고, 로고·활동 사진·타이포를 중심으로 구성합니다.
- 첫 화면 CURIOUS BY NATURE의 대형 타이포·블루·금속성 조형물·작은 주석을 전체 스타일의 기준으로 유지합니다. 연결선과 조형물 간격에 맞춰 주변 배치를 조정했습니다.
- 첫 화면의 파란 3D 구체에서 얇은 선이 시작되어 01의 로고 주석, 02의 기둥, 03의 회로 입구로 이어집니다. 구체의 화면 좌표를 투영해 부유·드래그 시에도 출발점이 따라갑니다. 스크롤 위치에 맞춰 그려지고 기둥에 닿으면 폭이 넓어집니다. 01은 로고 프레임과 소개 문구를 엇갈려 배치합니다. 모션 정지/동작 줄이기에서는 추가 연결선을 숨깁니다.
- 소개는 큰 원본 로고, 전시 캡션과 주석선, 검정·회색 타이포로 구성합니다. 로고 부유와 주석선 애니메이션을 겹칩니다.
- 활동은 밝은 배경을 유지하며, 파란 기둥·대형 활동명·엇갈린 사진·앞쪽 설명이 겹치는 전시형 구성입니다. 사진 펼침과 타이포 시차는 스크롤에 연동됩니다.
- 소개와 활동 사이에는 원본 INCOM 로고와 작은 워드마크가 스크롤과 무관하게 계속 수평 이동하는 띠를 배치합니다.
- 연혁의 파란 선과 네모 노드는 처음에 숨겨집니다. 스크롤에 따라 선이 그려지고 해당 지점에 도달하면 노드가 나타납니다. 표시점·시점·노드 등장은 시간 기반 루프 없이 스크롤 위치만 사용하므로 스크롤을 멈추면 멈추고 되돌리면 역재생됩니다. 추가 스크롤은 800px이며 버튼으로 각 노드까지 이동할 수 있습니다.
- 동작 줄이기 또는 모션 일시정지 시 활동은 밝은 배경, 연혁은 정적인 전체 목록으로 표시하고 로고 띠를 멈춥니다. 연혁 모듈 실패 시에도 내용을 읽을 수 있습니다.
- 연혁의 큰 표시점은 모서리에서 눌렸다 복원되며 회로판 아래로 나옵니다. 이어지는 선은 성과 목록 옆으로 내려와 수상 항목 네 개에 각각 연결됩니다.
- 03→04 연결선은 대각선으로 왼쪽 여백에 진입합니다. 수상 목록을 지난 선은 05 시작점까지 내려온 뒤 파란 면으로 확산하며 연락처 섹션을 채웁니다. 스크롤 역방향·동작 줄이기·키보드 포커스 대안을 지원합니다.
- 성과는 수상 목록, 연락처는 블루 배경의 대형 한글 타이포로 구성합니다.
- 소개·역사·세부 활동·수상 내역·연락처를 보존합니다. 운영진은 같은 사이트의 `/team/`으로 연결합니다.
- 원본 `2026-INCOM/incom-homepage`의 메인·운영진·404 구성을 유지합니다. 데이터 기준 커밋과 이미지 출처는 `assets/team/SOURCES.md`에 기록했습니다. 별도 활동·수상 상세 페이지나 미확인 개인 정보는 추가하지 않았습니다.
- 운영진은 음료 오브젝트 선택 레퍼런스를 해석한 캐릭터 선택 무대입니다. 화면의 좌우 버튼 없이, 마우스를 누르고 끄는 거리만큼 캐릭터가 연속 이동하고 놓으면 가까운 캐릭터에 감속하며 안착합니다. 터치 스와이프, 키보드 방향키, 직책 선택도 지원합니다. 자동 넘김은 없으며 JavaScript가 없으면 정적 운영진 목록이 표시됩니다.
- 동작 줄이기 설정, 모션 일시정지, 화면 밖/백그라운드 렌더링 중지 지원.
- WebGL을 사용할 수 없어도 기존 오브젝트 이미지와 모든 본문이 표시됩니다.
