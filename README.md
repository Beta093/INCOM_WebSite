# INCOM — A space for curious minds

인하대학교 컴퓨터 연구분과 중앙동아리 INCOM의 홈페이지 리디자인 초안입니다.

기존 사이트의 소개, 역사, 활동, 성과, 연락처 콘텐츠를 유지하면서 오브젝트 기반의
디지털 전시 공간처럼 탐색할 수 있도록 시각 구조와 인터랙션을 새롭게 구성했습니다.

## 미리 보기

별도 패키지 설치 없이 아래 명령으로 로컬 서버를 실행합니다.
3D ES 모듈을 사용하므로 파일을 직접 여는 대신 HTTP 서버로 접속해야 합니다.

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4173`을 열면 됩니다.

## 구성

- `index.html` — 전체 콘텐츠와 접근성 구조
- `gallery.css` — INCOM 블루·크림·실버 팔레트와 반응형 전시 레이아웃
- `gallery.js` — 커튼 오프닝, 스크롤 등장, 모션 일시정지
- `scene.js` — 드래그 가능한 실제 WebGL 조형물과 절전 렌더링
- `assets/` — 기존 INCOM 공개 사이트에서 보존한 로고와 활동 이미지
- `assets/vendor/` — Three.js 0.180.0 고정 버전과 MIT 라이선스

## 디자인 방향

- 상단 내비게이션 없이 화면 전체로 시작하는 전시. 바로가기는 푸터에 배치합니다.
- 대표색은 파란색. 이 초안의 블루는 `#2457ed`이며 공식 색상 코드가 정해지면 교체할 수 있습니다.
- 짧은 블루 커튼 오프닝 → 크롬 매듭과 파란 구체 → 스크롤로 쌓이는 활동 패널.
- 모바일은 각 패널을 순서대로 읽을 수 있도록 일반 세로 흐름으로 표시합니다.
- 소개·역사·세부 활동·수상 내역·연락처를 보존합니다. 운영진은 기존 사이트로 연결합니다.
- 동작 줄이기 설정, 모션 일시정지, 화면 밖/백그라운드 렌더링 중지 지원.
- WebGL을 사용할 수 없어도 기존 오브젝트 이미지와 모든 본문이 표시됩니다.
